👥 Groups

Manage group memberships and group-level access grants.

Create Group POST /api/groups?groupId={groupId}
Response 200
Add Member POST /api/groups/{groupId}/members/{memberId}
Response 200
Grant Group Access POST /api/groups/{groupId}/access/grant
Response 200
Delete Group DELETE /api/groups/{groupId}
Response 200
Remove Member DELETE /api/groups/{groupId}/members/{memberId}
Response 200
Revoke Group Access DELETE /api/groups/{groupId}/access/revoke
Response 200
Get All Members GET /api/groups/{groupId}/members
Response 200

📄 Resources

Manage resource permissions and hierarchy.

Create Resource POST /api/resources
Use {{$randomUUID}} to generate a random UUID.
Response 200
Grant Permission POST /api/resources/grant
Response 200
Check Permission GET /api/resources (with query params)
These will be sent as query params (resource, resourceId, permission).
Response 200
Get Hierarchy GET /api/resources/hierarchy
Response 200
Revoke Permission DELETE /api/resources/revoke
Response 200
Delete Resource DELETE /api/resources (query params)
Response 200
